# @erp/config

Shared tooling configuration used by every app and package:

- `tsconfig/base.json`, `node.json` (NestJS, Electron main), `library.json` (packages built with tsup), `react.json` (Vite apps)
- `eslint` — flat configs `node` and `react`
- `prettier` — formatting rules (the repo root points at it)
